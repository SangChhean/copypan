# 问答系统 v4.0 功能列表

2026-11-17 更新：按已完成的后端（检索、取篇、流水线）与流程设计同步。标【新增】的是 4.0 相对 3.0 新增的；标【11-17更新】的是本次相对上一版（11-11）修改或补充的。

## 一、核心问答

- 自然语言提问，答案严格引用职事信息原文
- 流式输出（打字机效果），并显示处理进度（理解问题、找材料、把关、生成）【11-17更新】
- **多轮对话：**追问先改写成完整的问题，继承前面的作者、年代等限定；带最近 3 轮上文【11-17更新】
- **拒答作为正常输出：**超出语料范围、证据不足时明确拒答；只能回答一部分时，如实回答这一部分并说明缺什么；放宽条件重试一次后仍不够，才拒答【新增】
- 引用书目自动列出，统一列在回答最后；正文里用编号对应出处，书目由程序按编号生成【11-17更新】
- **引文逐字核对：**程序核对「」内是否确为原文；核对不过的，在回答里标〔未核实〕并留记录【11-17更新】
- **原话与归纳分开标注：**归纳只能由前面引出的原文支持，不下新结论；职事没有直接讲到的，如实说没有【新增】
- **答案按题型组织：**定义类按「内在素质、个人经历、团体彰显」展开，比较类先分述两边再说明区别，汇集类分组列出，发展类按阶段排列，召会生活类先引原话再简单归纳；回答开头用一两句话交代前提（对问题的理解、只找到部分材料、只找到近似内容、年代范围等）【新增】
- **复杂问题拆开回答：**一个问题涉及几个对象、来源或角度时，拆成最多 4 个子问题，分别找材料，再合起来回答；简单问题不拆【新增】

## 二、问题理解与分类

- **问题分类更细，每类走各自的流程，细分原来的「一般」：**指明具体对象的定向问题七种（按作者、年代、生命读经、节期纲目、注解、诗歌、经文）；一般问题十类（定义、比较、个人经历、团体实行、召会生活、汇集、核实说法、反找经文、发展、默认）【11-17更新】
- **汇集类提问：**把职事里关于某个主题的话集中起来，取量更大，按出处分组列出；原「列举」并入默认——只问一个词时，改成「某某有哪些」来处理【新增】
- **定义类提问：**直接用词条定义回答，再用原文补充【新增】
- **比较类提问：**两个对象各检索一次，再说明区别；两个对象都要有材料，缺一边时如实说明【新增】
- **个人经历、团体实行类提问：**个人经历优先找生命读经和倪柝声文集；团体实行优先找李文集 1985 至 1993 年的内容【新增】
- **召会生活类提问：**针对基督徒生活、召会生活中实际遇到的疑难（例如处境里该不该、能不能、怎么处理）；拆成经文根据、真理原则、召会的处理与实行、个人经历与操练等角度分别找材料；以职事的原话为主，加简单过渡和归纳，不下新结论【11-17新增】
- **核实说法类提问：**先找原话；只找到意思相近的内容时，如实说明，不当作原话【新增】
- **反找经文类提问：**先用真理点与经文的对应，再用定义中的读经资料，最后到圣经材料中检索【新增】
- **发展类提问：**按阶段排列，已有整理好的发展内容的词优先使用【新增】
- **指明具体对象的提问：**生命读经、节期纲目、诗歌、注解、经文直接调取原文，不经检索与把关，按顺序完整显示；取不全或缺篇时明确告知缺哪里；生命读经和节期的某一篇另附摘要，诗歌和注解不写摘要【11-17更新】
- **敏感或辩证问题：**作为标记处理，附上真理辩证资料作参考，回答语气平稳【新增】
- **限定条件识别：**从问题里抽出年代、作者，检索时作过滤；年代只对李常受文集生效，倪柝声文集没有年代；条件互相冲突（如倪柝声加年代）时，告知用户职事信息里没有；没把握时不硬限定，回答开头说明对问题的理解【新增】
- **推荐重点：分五层：**问题里明说的词（不限于词条）、真理启示、内在素质（只从最内在的词里选）、生命经历、实行应用；每个题型各层的个数不同，总数不超过八个，拆分的问题可以多一点；每个词都由程序核对确实在词条清单里；不把内在的词硬加到外在的问题上【11-17更新】

## 三、经文问答

- 识别经文查询意图，支持单节 / 范围节 / 整章三种查询；识别各种常见写法（简称加中文章、范围、跨章等），整章不设上限【11-17更新】
- 圣经原文即时展示
- 经文注解展示（可折叠）
- 串珠引用展示（按标签分组，可折叠）
- 经文下方自动附上相关职事信息内容
- 章节附上生命读经内容
- 章节附上希腊原文对照

## 四、诗歌问答

- **识别诗歌查询意图：**输入某一首诗歌的首数，即可调出该首诗歌；大本与补充本号码有重叠时，默认大本，可指明补充本；问到没有收录的首数，如实说明【11-17更新】
- 覆盖大本、补充本诗歌，诗歌全文即时展示【新增】

## 五、检索与图谱

- 全部使用 4.0 新索引【新增】
- 使用 4.0 新图谱（词条、主干、枝子、经文节点、29 种关系）【新增】
- 图谱提供词条定义、真理辩证资料、真理点与经文的对应、高峰与有机发展内容；词条之间的关系第一版暂不使用【新增】
- **检索按问题类型分别处理：**作者、年代是硬限定，个人经历、团体实行是优先范围；每个推荐重点另找一轮；复杂问题按子问题分别检索；重复内容去掉，同一篇的段数设上限【新增】
- **材料把关：**逐段判断，整体分「够、部分够、不够」；复杂问题按子问题分别判断；不够时放宽条件再找一次（仅一次）【新增】
- 防火墙命中后的处理：放进检索结果最前，失败时留记录【新增】

## 六、数据与缓存

- 与纲目侧数据同步：纲目是源头，问答单向跟随，机制待设计【新增】
- 数据更新后，由管理后台清空旧答案缓存（缓存不再随数据版本自动失效）【11-17更新】
- **「未找到」的缓存：**只在放宽重试后仍不够时才保存，保存一天；调取具体对象的结果不缓存；降级的结果不缓存【新增】
- Redis 结果缓存

## 七、多语言

- 简体 / 繁體 / English 三语切换
- 繁体本地转换（OpenCC），英文翻译；翻译涉及原话的处理办法待讨论【11-17更新】
- 译文缓存（二次切换秒回）
- 经文原文 / 注解 / 串珠直读三语原文字段，不走翻译

## 八、语音输入

- 麦克风录音，点击开始、点击结束
- gpt-4o-transcribe 转写
- AI 保守校对（专有词纠错），填入输入框（词表可改用 4.0 词条）

## 九、朗读

- MiniMax 朗读
- 暂停 / 继续，百分比进度显示
- 专有词发音纠错

## 十、答案操作

- 一键复制答案（去 Markdown，含引用书目，当前语言版本）
- 👍 / 👎 答案质量反馈

## 十一、用户系统

- 邀请码注册；用户独立于旧版问答【11-17更新】
- 每日问答次数限制（默认每天 30 次，可在管理后台按人调整）【11-17更新】

## 十二、管理后台

- 请求统计（总数、平均耗时、平均成本）
- 缓存管理（查看 / 按需清空）
- 调试面板（查看流水线各阶段详情，随新流程调整）；查看单个问题的完整处理记录，仅管理员可见【11-17更新】
- 邀请码生成与管理，用户列表与删除，调整每人每日次数【11-17更新】
- 日志带时间戳，能区分「未找到」的原因；每个问题记录各步结果（问题原文与上文、分类、重点词、各路取回数、把关结论、是否重试、版本、耗时），某一步出错时用保守办法继续并留记录；普通日志里不写问题原文，处理记录保留 90 天【11-17更新】

## 十三、平台与稳定性

- 手机端全功能适配
- HTTPS 部署，支持大量用户并发
- 独立的 Neo4j 与 ES，与纲目侧、主站分开部署【新增】
- 评测集：覆盖多个索引、词条、经文【新增】
