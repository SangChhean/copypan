## A. 答案生成 / 引文与版式（3.0 Step4 ↔ 4.0 step8）

### A1. 【核心要点】+ 主旨必须是原文原句

- **3.0 要点（引原文）**：`STEP4_ANSWER_GENERATION`「## 回答要求」第 1 条：「先立主旨」；「段首必须加「【核心要点】」标记」；「严禁用自己总结的话替代原文作为主旨句」。（`back_qa/qa/prompts.py` STEP4，约 L106）
- **4.0 草稿**：`step8_v0.1.txt` 无「【核心要点】」标记要求；无「主旨必须是原文原句、禁止用自己总结替代主旨」的同等指示。有「开头只在需要时写一两句前提说明」。

### A2. 「」内一字不差；禁止改写/缩写/意译后放入「」；禁止多处原文拼进同一对「」

- **3.0 要点（引原文）**：第 3 条「让原文说话」：「「」内必须是逐字照录的原文，一字不差…；严禁将多处原文拼接后用同一个「」括起来；严禁对原文进行任何程度的改写、缩写或意译后放入「」；若需引用多处原文，每处原文单独用一对「」括起来」；「优先引用"字义"相关原文段落」。（STEP4 约 L108）
- **4.0 草稿**：`step8_v0.1.txt` 要求「原话用「」括起，必须是同一段里连续原句；可用「……」省略中间…」——允许省略号半段；未写「优先字义段落」；未用「严禁改写/缩写/意译后放入「」」的同等措辞。

### A3. 小标题推进论述 + 禁止「…的原则」「…的真理」等规范性措辞

- **3.0 要点（引原文）**：第 4 条：「小标题应推进主旨的展开…；标题措辞取自原文，严禁用"…的原则"、"…的真理"等规范性措辞」。（STEP4 约 L109）
- **4.0 草稿**：`step8_v0.1.txt` 明确「不要用 # 标题、* / - 列表、**加粗**」；无「小标题推进论述 / 取自原文 / 禁规范性措辞」条款。

### A4. 衔接语从简；解说篇幅不可超过原文

- **3.0 要点（引原文）**：第 5 条「衔接语从简…不可超过原文篇幅」；第 9 条「严禁：改写或总结原文；自己的解说篇幅不可超过原文」。（STEP4 约 L110、L114）
- **4.0 草稿**：`step8_v0.1.txt` 有「归纳与原话分开…〔归纳〕」与「不要为凑字数灌水」；无「解说篇幅不可超过原文」的同等上限表述。

### A5. 引用编号为纯数字；文末【引用书目】由模型输出

- **3.0 要点（引原文）**：第 6–7 条：「每段引用末尾标注纯数字编号（如 1），不加方括号」；「回答末尾输出【引用书目】，每条格式为"编号 完整书名"」；第 10 条书名「完整取用，不截断、不缩写；引用书目严禁重复」。（STEP4 约 L111–L115）
- **4.0 草稿**：`step8_v0.1.txt` 要求正文只写 `[n]`，「书目由程序生成，不要写「【引用书目】」」——编号形态与书目责任与 3.0 不同；无「纯数字不加方括号 / 模型自写完整书名清单」指示。

### A6. 严禁出现 chunk_id、文件名、段落编号等技术字符串

- **3.0 要点（引原文）**：第 8 条「严禁：出现 chunk_id、文件名、段落编号等技术字符串」。（STEP4 约 L113）
- **4.0 草稿**：`step8_v0.1.txt` 无该条明文。

### A7. Markdown 总标题 `## 总标题` + `**小标题**` 版式

- **3.0 要点（引原文）**：「## 输出格式」要求全篇 `## 总标题`、层次用 `**小标题**`；「严禁直接复述用户问题作为标题」。（STEP4 约 L123–L127）
- **4.0 草稿**：`step8_v0.1.txt` 要求**不要**用 Markdown 标题/加粗（前端不渲染）。版式指示方向相反。

### A8. 只问一个词/短语时的「概述＋逐项要点」写法（含「神的名」）

- **3.0 要点（引原文）**：第 12 条整段（c8b28a72 新增）：「不要只写成主题概览，要写成「概述＋逐项要点」」；逐项小标题、每项先极简释义再引原文；「只列所给段落中确实出现的项目…不得凭自己的知识补充」。（STEP4 约 L117–L121）
- **4.0 草稿**：`step8_v0.1.txt` / `step3_v0.1.txt` 无同等「只问一词 → 概述＋逐项要点」写作规程。`step3` 有「只问一个词或一般问题 → 默认」的题型归类，不是答案版式规程。

### A9. 原文与经文/原文词「引入时机」

- **3.0 要点（引原文）**：第 11 条：「题目中的关键词直接涵盖，需要时可在答案中自然提及希腊/希伯来原文或经文」。（STEP4 约 L116）
- **4.0 草稿**：`step8_v0.1.txt` 无「希腊/希伯来原文引入时机」指示（4.0 输入项有 3a 定义，但提示词未写「自然提及原文/经文」的同款时机规则）。
