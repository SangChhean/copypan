# 3.0 → qa4 功能搬迁盘点（简表）

依据：问答系统 v4.0 功能列表。原则：界面/交互尽量原样；数据用 qa4。

| 组 | 功能 | 现状 | 备注 |
|----|------|------|------|
| 1 | 经文问答（原文/注解/串珠/职事/生命读经/希腊对照） | **已搬** | `verse_data` + `BibleMessage`；职事摘要在经文块下 |
| 2 | 诗歌（大本/补充本按首数） | **已搬** | `hymn_data` + `HymnMessage`（全文/折叠/说明）；重号默大本；歌词多选 choose |
| 3 | 用户系统（邀请/限额/登录） | **已搬** | 登录/邀请注册页同 3.0；`/api/auth/usage`；页头 `今日 used/limit`；用尽提示同 3.0；退出登录；管理页可生成邀请码/调额度 |
| 4 | 答案操作（复制/赞踩）、三语、语音、朗读 | **已搬** | copy/👍👎 同 3.0；简体/繁體/English；ASR=MediaRecorder+/api/asr；TTS=MiniMax /api/tts/minimax |
| 5 | 管理后台、手机适配 | **已搬** | 后台 tabs：统计/缓存/邀请码/用户/记录；删用户+反馈汇总+清缓存；`/admin` 需登录+X-Admin-Token；手机 768px 固定顶底栏。未搬：调试 Tab（qa4 无 `/api/qa/query`） |
| 6 | 整体界面对齐 3.0 | **已搬** | 楷体顶栏+头像菜单+新对话；欢迎示例；金底用户气泡；加载 spin；书目/免责/输入区同 3.0。保留 4.0 角标/##标题/计划进度/诗歌块 |

流水线第 2–9 步逻辑不改；经文/诗歌展示走编排器定向分支增发 `verse_data` / `hymn_data` + 前端接线。
