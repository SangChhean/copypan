# prompts（阶段 0 占位）

本目录后续放提示词模板。阶段 0 **不写入任何提示词正文**。

## 约定变量（后续模板将使用）

- `{{query}}`：用户问题原文
- `{{lexicon_hits}}`：命中词条列表（含档次 / same_as）
- `{{zui_neizai}}`：最内在名单中的命中词
- `{{trunk_branch}}`：主干 / 直接枝 / 间接枝上下文
- `{{verse_refs}}`：规范化经文引用
- `{{wenji_years}}`：文集年代筛选结果
- `{{retrieval_chunks}}`：检索片段
- `{{author}}`：作者约束（李常受 / 倪柝声 / 恢复本圣经）
- `{{fake_llm}}`：是否走假回复路径

具体模板文件在后续阶段添加。
