# organic_advance.json

## 这是什么

「生机关联的进展」（organic advance）专特标注的**内容文件**：每个题目一篇已作好的 2～3 页纲目，共 **70** 条、**69** 个词条。

**2026-11-15 换成新版**（字段与旧版不同）。每条只有三个字段：

- `name`：词条名（对图谱 `Truth_Point.name`）
- `title`：纲目题目（如「圣经—神的话」「基督的神性与人性」）
- `content`：整篇纲目文字——第一行「读经：……」，接着每个有资料的阶段一个大纲（「壹　倪柝声弟兄职事：」……），底下中纲「一　……」

说明：

- 两个词共用一份资料的，两个词各一条、`content` 相同：圣经／神的话、圣经／结晶意义、基督的神性／基督的人性、基督的身位／基督的工作、帐幕／圣殿。
- 「圣经」有两条：《圣经—神的话》和《圣经的结晶意义》。
- 其中 5 个（信、约、基督的丰满、金灯台、时代的职事）是 3a 按六阶段重排后整理成的纲目。
- 名字对应（用户 2026-11-15 定）：本文件里 name 为「基督的十字架」的那一篇（《基督的十字架》），就是图谱词条「基督的死」的生机纲目；本文件不改名，程序读取时把「基督的死」对应到这一篇。

旧版（2026-11-06，`name`、`series`、`stages`、`content_1`…`content_6` 各阶段原资料，38800482 字节）已不再使用。

## 与图谱的关系

图谱里 `Truth_Point` 节点的标注 `organic_advance = true` **只表示**：该词条在本文件里有内容。

内容本身**不在**图谱里；检索时按词条名 `name` 到本文件取。

这是例外：其他专特标注的内容都在图谱节点里。
