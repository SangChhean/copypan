### #19 参考优先版（v2）

### B 摘录版
神是亚伯拉罕的神、以撒的神、雅各的神。这三人的历史乃是一个人的三方面：三一神在蒙召者身上作工，要将祂自己作到人里面，使天然的雅各成为神的以色列。

在亚伯拉罕身上，我们认识神是父，是呼召的源头。祂把我们带到断定自己已死，好信那叫死人复活、使无变为有的神（罗四17）。在以撒身上，我们认识子神；父把祂的儿子分给我们，我们的一切都是承受与享受。在雅各身上，我们认识那灵的管教，神借此对付我们天然的人。这三面互相成全，才是一个完整的经历。

雅各原先占有的一切被倒空，神便用神圣生命的元素充满他，他就改名为以色列（创三二28），在他身上有神的彰显，也有神的权柄。这以色列繁增为以色列家，就是神的家；神所要的不是单个的人，乃是一个团体的器皿。

为此，我们要天天将十字架摆在天然上，在难处中不凭手腕抓夺，乃顺服那灵的管治，安息承受神的预备。至终，我们照着新造的准则，以经过过程的三一神作生命和生活而行，成为神的以色列（加六16），彰显神并为神掌权。

### C 直写版
神称自己为亚伯拉罕的神、以撒的神、雅各的神（出三6）。这乃是三一神在一个蒙召者身上三面互相成全的工作，我们需要认识并经历这三面，才能被神作成神的以色列（加六16）。

在亚伯拉罕身上，我们看见父神是一切的源头。祂以荣耀呼召我们，叫我们信那叫死人复活、使无变为有的神（罗四17），过祭坛与帐棚的生活。

在以撒身上，我们经历子神作恩典分赐给我们。天然的努力停下来，我们才能安息于接受，承受父一切的丰富。

在雅各身上，我们经历那灵的管治。祂借着环境对付我们天然的手腕与抓夺，使我们在毗努伊勒被破碎；神圣生命的元素就加进来，使抓夺者变化成为以色列，在生命里成熟，能祝福人，彰显神，并有神的权柄。

这样被变化的人，在伯特利成为浇了油的柱子，与众圣徒一同被建造成为神的家，就是召会。为此，我们要在凡事上不信靠自己，转向灵接受恩典，并甘心让那灵借着主所量给的对付变化我们。至终，我们要作新造中神的以色列，同被建造进入新耶路撒冷，使神得着彰显与代表。
