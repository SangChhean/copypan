## tag

彼此互相

## definition

彼此互相乃是身体的特点，身体尽功用乃是彼此互相的；彼此互相乃是召会聚会的基本原则，在我们的聚会中，讲说神的话应该是彼此互相的，而不是个人的，彼此互相（而非个人）应当普遍的实行。彼此互相是双向的，不是单向的，因为它的属灵内涵是交通，交通是双向的。

## note

“彼此”、“互相”的希腊原文是一个字，意义一样。在中文里面，“彼此”和“互相”都能表示双向的关系，最大的差别在于词性与语法功能。“彼此”既是代词（名词）也是副词，既可以当作主语、宾语，也可以放在动词前当副词；“互相”是副词，只能放在动词前面修饰动作，不能当作主语或独立的名词使用。彼此互相是双向的，不是单向的，因为它的属灵内涵是交通，交通是双向的。
