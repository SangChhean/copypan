### 1.4 处理管线顺序（强制）

对每一篇 docx，必须按以下顺序处理，**不得调换**：

```
① 篇头识别（4.4 / 4.5 / 4.6）
        ↓
② 截断（第三节）——先确定摘录起点，之后的段落一律不再参与任何判定
        ↓
③ 层级判定（2.1~2.6）——只在截断之前的范围内运行
        ↓
④ 无编号段并入上一纲目点（2.7）——同样只在截断之前的范围内
        ↓
⑤ 非纲目文件判定（第五节）
```

**为什么顺序是强制的**：实测摘录正文里存在「（一）"你们……离弃了偶像转向神"（帖前一9）。」这类括号编号后直接接正文的段落。若截断未先完成，2.2 节扩开后的编号识别会把职事原文当成纲目点收进来；2.7 的「无编号段并入」更会把整篇摘录并进最后一个纲目点。**截断是 2.2、2.7 两条规则的安全前提。**

### 2.2 轨二：段首文字编号

层级信息写在段首的，形如 `编号 + 分隔符 + 正文`。

**主分隔符表**（`SEPARATORS`），下列任一均可：

| 分隔符 | 出现处 |
|---|---|
| Tab | A 批 Normal 体系主流写法，如 `壹→罪的结果是与神分开…` |
| 顿号 `、` | 《福音题纲》主流写法，3,598 段，如 `一、一个上流人` |
| 全角空格 `　` | 散见两批 |
| 半角空格 | 《福音题纲》13 段 |

**括号类编号可直接接正文**（无分隔符），即 `（一）`、`（1）`、`（a）` 之后可以紧跟文字。实测《福音题纲》有 109 段。

> **非括号编号必须带分隔符**，不得允许直接接正文——否则「一九三二年…」「三节经文…」会被误判。这条是硬性限制。

**兜底分隔符（v0.4 新增）**

`FALLBACK_SEPARATORS = ["，"]`（全角逗号），**与主分隔符表分开定义**。

> 逐篇处理：先用主分隔符表解析一遍；**当且仅当该篇纲目点数为 0 时**，把全角逗号并入分隔符重试一遍；重试结果纲目点数 **≥2** 才采纳，否则保留第一次的结果。
> 采纳兜底结果的篇写入异常 `fallback_separator`。

**全角逗号不得加进主分隔符表**——它是最常见的标点，「三，四个月后…」「二，三年前」这类句子会被误判成纲目点。实测全库只有 1 篇走了兜底（《福音题纲》msg. 41「空、空、空」，编号写作「一，人生一切都是虚空」「1，加增知识的…」，认出 31 个点），印证了限定为兜底是对的。

取分隔符之前的文字作为 `label`（括号类取整个括号），按下表定级：

| 层级 | 编号字符 |
|---:|---|
| 1 | 壹 贰 叁 肆 伍 陆 柒 捌 玖 拾 |
| 2 | 一 二 三 四 五 六 七 八 九 十 十一 …（含「百」） |
| 3 | 阿拉伯数字 1 2 3 … |
| 4 | a b c … z |
| 5 | （一）（二）… |
| 6 | （1）（2）… |
| 7 | （a）（b）… |

### 2.4 双轨的合并规则

1. 两轨都命中且层级相同 → 采用，`level_source = "both"`；
2. 只有一轨命中 → 采用该轨，`level_source = "style"` 或 `"text"`；
3. 两轨都命中但**层级不同** → **以文字轨为准**，`level_source = "text_over_style"`，同时写入异常 `level_conflict`；
4. 两轨都不命中 → 见 2.5、2.7。

> **依据**：`coverage_checks.md` 第三项对 848 条 `level_conflict` 抽样 20 条，逐条核对上下文编号连续性，结论是**文字轨对 20 条、样式轨对 0 条**——样式名套深或套浅，而编号字符与前后文是接得上的。
>
> 受影响最大的单篇是《李常受弟兄个人笔记》：v0.2 时 283 个点因样式全是 `3中点` 被压平为第 2 级（该篇独占 192 条冲突），`min_level` 变成 2，切块会产出 283 个极短块。改为文字轨优先后层级恢复为 `{1:67, 2:83, 3:125, 6:8}`，`min_level` 回到 1，切出 67 个单位。

### 2.5 无编号的纲目点

- **A 批「前言」**：共 516 段，其中第 1 级 460 段（样式 `2大点` 457、`大点` 3）、第 2 级 49 段、第 3 级 7 段。位置在读经之后、「壹」之前。
- **B 批【纲目的原文】**：没有「序言」「前言」，只有「添言」1 段、「附：」4 段。

规则：**段落样式属于层级样式表** → 即便段首无编号，也按样式定级，`label` 取段首文字（到第一个分隔符或标点为止），`level_source = "style"`。

### 2.6 label 取值前先剥前导 Tab

实测有段落在编号之前多出前导 Tab，形如 `→(一)→两种话都是圣的…`。

规则：**取 label 前，先剥掉段首的全部前导 Tab 与空白字符，再按分隔符切分。** 剥掉的内容不计入 `text`。A 批有 800 个、B 批 523 个「段首即 Tab」的段落，本规则一并加固。

### 2.7 无编号段并入上一纲目点

《福音题纲》是「题 + 说明」体例：纲目点之后紧跟无编号的说明文字。领导与 Srey 已定：**说明文字是职事原文，要保留**。

规则（**只在截断之前的范围内生效**，见 1.4）：

> 一个段落若**既不属于层级样式、段首又无编号**，且本篇**已经出现过至少一个纲目点**，
> 则把它的文字并入**上一个纲目点**的 `text`，用换行符 `\n` 分隔；
> 在该 point 上置 `has_note = true`，并把被并入的原段号追加进 `note_para_nos`；
> 本篇累计并入数写进 `stats.merged_note_paras`。

配套约束：

- 空段（去空白后为空）直接丢弃，不并入，不计数；
- 排在**首个纲目点之前**的无编号段落不并入（篇头区域，由第四节处理）；
- **保护性异常**：若某篇被并入的说明段数 > 该篇纲目点数，写入异常 `note_overflow`。这条用来兜住截断漏网的篇——实测抓到 1 篇（`msg. 13 认识神新约的经纶`，整篇摘录被并进最后一个点），已由 3.2 节硬编码处理，v5 后该异常为 0。

实测并入量：A 批 440 段、涉及 145 篇；B 批 37 段、涉及 23 篇。

## 三、截断规则（去掉职事信息摘录）

### 3.1 规则

**标志文字清单（条件 A）**，一个段落**内部的任意一行**（按软回车 `\v` / `<w:br/>` 拆行）去掉首尾空白后等于下列之一：

- `职事信息摘录：`
- `职事信息摘录`（无冒号）
- `职事信息之摘录：`
- `职事信息摘要：`
- `听抄信息：`
- `晨兴圣言信息：`

冒号全角半角均可，句号亦可。

**条件 B — 「附：」开头**：段落（剥前导空白后）以 `附：` 或 `附:` 开头。

**截断动作**：

> **① 整段就是标志**（该段只有标志这一行）→ 该段及其后全部丢弃，`truncated_at` = 该段号，`truncate_rule` = `text:<标志文字>`。
>
> **② 标志是段落内部的一行**（前面还有正文）→ **保留该行之前的内容**作为该段的 `text`（该段仍按第二节参与层级判定），标志行及同段其后内容丢弃；**下一段起**全部丢弃，`truncated_at` = 下一段号，`truncate_rule` = `text_inline:<标志文字>`，并写入异常 `truncate_inline`。

**两条件的优先级**：

> 先扫全文找条件 A。**全文存在条件 A 时，截到该处**，忽略在它之前出现的「附：」。
> **只有全文不存在条件 A 时**，才在第一个「附：」处截断。
> 两者都没有则全文保留。

> **为什么标志要按行匹配**：实测标志常常挂在最后一个纲目点段落的末行，如
> `三→主的恢复不仅注意话，注意灵，并且注意生命；有话有灵，自然就有生命—约六63，林前十五45。⏎职事信息摘录：`
> 若要求「整段等于标志文字」就完全截不到：最后一个纲目点的 `text` 尾部挂着标志文字，整篇摘录正文未被丢弃。实测 A 批有 29 篇属此情形。
>
> **为什么「附：」要让位于条件 A**：A 批有的第 1 级纲目点本身就写成「附：……」（样式仍是层级样式），其后才是真正的摘录标志。若在这个「附：」处截断，会丢掉其后的全部纲目点。

|---|---:|---|

| 标志段用了别的样式（`Normal` 等） | 520 | **截不到**，摘录混入 |

文字规则是主，样式仅作辅助校验（两者不一致时写入异常）。已抽查验证：`truncate_text_late` 35 条中间只有空的摘录样式段，截断位置正确；`truncate_by_style_only` 8 条末段是空的摘录样式，没有附录可截。

### 3.4 切块分组基准

> 本节属下一阶段，详见《PanAI 4.0 纲目 chunks 与 ES 索引方案》第二节。

**切块单位**：一个分组点 + 其后直到下一个同级分组点之前的全部下属点。

**分组基准 = 本篇 `min(level)`**，而非固定的第 1 级。A 批有 622 篇整篇没有第 1 级点（《新约总论》续篇、《福音题纲》等），固定按第 1 级分组会让它们产出 0 个 chunk。

**残留点**：排在本篇首个分组点之前的 points，**并入本篇第一个单位**，不单独成块。实测 A 批 63 篇、867 个点，B 批 0。

**超长不拆分**：嵌入模型原生上下文 32,768 token，实测最长单位 5,653，余量充足。

**验证要求**：两批都不得有任何一篇产出 0 个单位。

### 5.1 判定条件

1. **条件 1（自动排除）**：截断之后的范围内，纲目点数量为 0；

- **55 篇确认排除**：通问汇刊、敞开的门、基督徒报卷五（故事／启事／书报评议／总目录）、介言与说明类。当初是条件 2 候选（有纲目点），自动规则抓不住。
