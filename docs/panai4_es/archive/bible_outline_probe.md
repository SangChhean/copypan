## 坐标与推导规则（实现摘要）

- 统一坐标键：`key = section_code * 1000000 + segment_code * 10 + unit_code`

- 纲目范围：同卷按 `volume_order`；从自身 key 到其后第一条 `level <=` 自身的纲目 key 之前；无则到本卷末
- 叶子：下一条 `level <=` 自身，或本卷最后一条
- 段落范围：同卷按 key；到下一段落 key 之前；最后到本卷末
